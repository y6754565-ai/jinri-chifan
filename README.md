# 今天吃饭

一个适合 iPhone 的中国家常菜推荐 PWA。

当前有 301 道带对应实拍图的菜谱参与匹配。支持语音、文字或按钮选择食材，
推荐过程完全在浏览器本地完成，不需要 API Key。

## 本地启动

```bash
npm run dev
```

打开 <http://localhost:3002>。

## 添加到 iPhone 主屏幕

用 Safari 打开 GitHub Pages 地址，点击分享按钮，再选择“添加到主屏幕”。

## 菜谱来源

本地菜谱包的部分菜谱与图片整理自开源项目
[Anduin2017/HowToCook](https://github.com/Anduin2017/HowToCook)，原项目采用 Unlicense。
